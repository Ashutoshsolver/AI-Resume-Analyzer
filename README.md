# AI Resume Analyzer

A simple web application that analyzes resumes using keyword matching.

## Features
- Upload Resume
- Detect Skills
- Resume Score
- Suggestions
- Modern UI

## Tech Stack
- HTML
- CSS
- JavaScript

## How to Run
1. Download the project
2. Open `index.html`
3. Upload a resume
4. Analyze skills instantly
